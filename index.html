    One-time setup guide (only if the first sync fails)
    1. Open your CloudBase console → 身份认证 → 登录方式, then turn Anonymous sign-in / 匿名登录 on.
    2. Create a database collection named exactly sw_ledgers, and pick the permission “All users can read, only creator can write / 所有用户可读，仅创建者可写”.
    3. If the app runs on a custom domain, add it under 安全域名 (add localhost for local testing).
    4. Come back here and press Turn on sync again.
